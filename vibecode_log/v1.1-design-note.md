# v1.1 交互与显示优化设计笔记

> 第二阶段：在 v1.0 功能完整的基础上，提升整体界面的优雅度、交互触感与视觉层次。

## 阶段信息

- **阶段**：v1.1（Phase 2）
- **时间**：2026-08-06
- **目标**：不动大结构、不增加新页面，仅通过字体层级、动效、材质、微交互的优化，让现有界面更精致。
- **约束**：保持现有字体（Playfair Display / Inter / JetBrains Mono），保持 v1.1 色调（米白 + 暖棕墨 + 鎏金）。

## 参考 Skill

本次优化主要参考以下前端设计 skill 的指引：

- **apple-design**：用于字体层级（tracking/leading）、空间一致性、弹簧感曲线、减少运动偏好、材质深度。
- **emil-design-eng**：用于微交互决策、按钮按压反馈、hover 优化、自定义贝塞尔曲线、性能规则。
- **find-animation-opportunities**：扫描现有代码，找出哪些状态变化缺少过渡、哪些可按压元素缺少反馈。
- **improve-animations**：审计当前动画实现，给出优先级和精确值。

### 明确不做的项

- **键盘/高频导航动画**：Navbar 的 NavLink 点击属于高频操作，不加额外动画，只保留 hover 反馈。
- **文章列表 stagger**：文章列表滚动浏览时已经是可见状态，再 stagger 会显得拖沓，仅在首屏 Hero 使用。
- **复杂物理弹簧**：不引入 Framer Motion / Motion 等库，全部用 CSS transition 或 `@starting-style` 实现，保持项目轻量。

## 设计决策

### 1. 自定义缓动曲线

在 `src/index.css` 中新增 token：

```css
--ease-out: cubic-bezier(0.23, 1, 0.32, 1);
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);
```

用于：
- `--ease-out`：按钮按压释放、卡片 hover 上浮、链接下划线
- `--ease-in-out`：下拉菜单、页面淡入

### 2. 动画时长

| 场景 | 时长 | 说明 |
|---|---|---|
| 按钮/卡片按压 | 100-160ms | 瞬间反馈 |
| hover 上浮 | 200-250ms | 自然跟随 |
| 链接下划线 | 300ms | 优雅但不过慢 |
| 下拉菜单入场 | 200ms | 轻快 |
| 页面淡入 | 200ms | 切换时不突兀 |
| Hero stagger | 50-80ms 间隔 | 首屏仪式感 |

### 3. 字体层级微调

- 大标题：`tracking-tight`（紧凑，显高级）
- 小标签/导航：`tracking-wide` 或 uppercase（增加辨识度）
- 正文：保持默认 tracking

### 4. 减少运动偏好

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

同时保留必要的颜色/透明度反馈（hover/active 颜色变化不依赖 duration 过长）。

### 5. 触摸设备 hover 保护

涉及 hover 的 transform 动画只在 `@media (hover: hover) and (pointer: fine)` 下生效，避免手机误触。

## Hero 视觉：巨型衬线水印 + 细线太阳纹章（方案 A）

- **背景**：最初尝试 3D 三角钢琴（多次迭代不理想，废弃）；后改为 SVG 飞鸟图样（偏简约、白卡片感重）。最终定为**方案 A**：不做卡片、不做边框，直接把视觉融进米白背景。
- **决策与实现**：
  1. **巨型衬线水印**：`Playfair Display` 超大号 "Born Free."（`clamp(4.5rem,17vw,17rem)`），鎏金色 9% 透明度，贴边出血，杂志封面感。
  2. **细线太阳纹章**：程序化 SVG（36 条长短交替射线 + 3 同心环 + 中心点），`currentColor` 描边，80s 缓慢旋转（`.sun-spin`），呼应 Born Free / 新日。
  3. **柔和辉光**：太阳背后径向渐变光晕，9s 呼吸（`.glow-pulse` + `.hero-glow`，含 dark 模式配色）。
- **文件**：`src/components/HeroSection.tsx`（背景层）、`src/components/SunOrnament.tsx`（纹章）。
- **动效**：全部纯 CSS；`prefers-reduced-motion` 下自动静止。
- **收益**：无 Three.js 依赖；水印与纹章均为代码生成，零素材；整幅背景融入米白，克制的"大气"。

### 反馈迭代（用户确认后精修）

1. **太阳更真实**：圆盘改为径向金色渐变 + 细环纹理 + 日斑弧段，射线加到 72 根（长/中/短三档），颜色用 `--sun-*` 变量，**比水印更深更金黄**。
2. **社媒移动端可滑动**：`SocialLinks` 容器加 `overflow-x-auto + snap + no-scrollbar`，手机上可横向拖动（实测 416px > 视口 294px）。
3. **整体内容上移约 8mm**：Hero 内整体包装层 `-translate-y-6 md:-translate-y-8`，`min-height` 不变，下方 Article/Project/Memo 不露出。
4. **水印与格言区分**：背景 "Born Free." 改为 `italic` + `skewX(-30°)`，不再与正文字体同质化；格言加轻微 `text-shadow` 增加立体感。
5. 手机端大 "Born Free" 位于底部属可接受，保持不变。
6. **裁剪修复（范围限制）**：Hero 原被 `max-w-6xl` 容器限制（约 1104px），水印 "B" 左下角与太阳右侧圆被 `overflow-hidden` 裁掉。改为 `.full-bleed`（`width:100vw; margin-left:calc(50% - 50vw)`）让 Hero 铺满整个视口，并加 `html{overflow-x:clip}` 防横向滚动；水印以左下角为锚点倾斜、太阳收进右侧。实测三种视口下水印/太阳均完整可见。
